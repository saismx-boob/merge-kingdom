1. PITCH
----------------------------------------------------------------
Merge game (fusion d'objets sur grille) + tower defense léger, dans
un univers d'Afrique du Nord + Afrique de l'Ouest unis par les
routes caravanières transsahariennes. Le joueur incarne Lumo, guide
de caravane, qui restaure "le Réseau" — le commerce et les contes
entre Numidie (Nord) et les empires du Sahel (Sud) —face aux
Prêtres de l'Éclipse qui corrompent les terres. Purifier un Prêtre
(le "méchant" local) le libère : il devient un allié offrant un
bonus permanent. Ton : chaleureux, épique-serein, conteur (griot).

DIFFÉRENCIATEUR : premier merge game à identité afro-fantasy
(Numidie/Massinissa/Jugurtha/Kahina-Dihya + Wagadu/Sunjata/Bida +
Mami Wata + folklore des tambours). Aucun plagiat des jeux chinois :
mécaniques de genre communes (merge/commandes/énergie) mais univers,
noms, histoire et direction artistique 100% originaux.

2. BOUCLES DE JEU
----------------------------------------------------------------
BOUCLE COURTE (30 s - 2 min) — dopamine :
 Taper un générateur (coûte 1⚡, 20% de chance d'item bonus, 20%
 de taps gratuits si Kossa libéré) → items Nv1-3 → glisser pour
 fusionner 2 identiques (NvX + NvX = NvX+1) → livrer les COMMANDES
 des PNJ → or + XP + fragments (le combat nourrit la grille).

BOUCLE MOYENNE (par session) :
 L'or achète de l'énergie (+10 pour 40🪙), paie les Racines d'Ombre
 (cases verrouillées) et fonde les relais sur la Carte.
 Le combat (vagues) donne or, XP, fragments, et DÉBLOQUE la
 purification des régions.

BOUCLE LONGUE (jours) :
 XP → niveaux → nouvelles commandes. Or → nouvelles régions.
 Vagues → purification des Prêtres → 6 alliés à libérer, chacun
 avec bonus permanent. Fin : purifier l'Avatar de l'Éclipse.

CHIFFRES CLÉS (data.js, modifiables) :
 - Énergie : max 80, régén 1/45 s, départ 40. Achat : +10 / 40🪙.
 - Grille : 7×7 = 49 cases. Racines : 29 cases verrouillées au sud,
  niveaux 1-6, brisées par fusion adjacente de niveau >= requis,
  ou payées 20×2^(n-1) 🪙 (20/40/80/160/320/640). +2⭐ par racine.
 - Drop générateur : 85% Nv1 / 12% Nv2 / 3% Nv3. Bonus +1 item 20%.
 - XP par niveau : 20 + 25×(niveau-1). Max joueur 20.
 - Combat : vague w → ennemis 1+floor(w/2) (max 4), lvl≈w/2,
  HP=12×lvl, ATK=3×lvl. Boss (w%5=0) : HP×2.2, ATK×1.3, récompense×3.
 - Récompense vague : 15×w (× mult or). Fragments : 60% chance
  créature Nv1-2 ; boss → trésor Nv2 garanti.

4. LA CARTE "LA ROUTE DE L'OR" (meta-jeu)
----------------------------------------------------------------
6 régions, 3 états : verrouillée (payer or + niveau) → corrompue
(un Prêtre de l'Éclipse, purifier en battant la Vague X) → purifiée
(allié libéré, bonus permanent, fond d'écran du jeu change).
 R1 Timgad (🏛️) : relais gratuit, Vague 5 → Dihya 🐪 : +10% or.
 R2 Oasis de Sel (🏝️) : 500🪙 Nv3, Vague 8 → Azizi 🧞 : énergie 25%.
 R3 Ruines de Wagadu (🏜️) : 2000🪙 Nv5, Vague 12 → Bida 🐍 : +15% XP.
 R4 Boucle du Fleuve (🦛) : 6000🪙 Nv7, Vague 16 → Mami Wata 🧜‍♀️ : +15% ATK.
 R5 Forêt des Tambours (🌳) : 15000🪙 Nv9, Vague 20 → Kossa 🥁 : 20% taps gratuits.
 R6 Trône de l'Éclipse (🌑) : 40000🪙 Nv12, Vague 25 → Aube 🌅 : +20% or & XP.
Les multiplicateurs se cumulent. État sauvé : unlockedRegions /
purifiedRegions dans localStorage.

7. ARCHITECTURE TECHNIQUE
----------------------------------------------------------------
Fichiers (vanilla JS, aucun framework) :
 index.html   — squelette des 3 écrans (Royaume/Route/Combat) + HUD.
 style.css    — tout le style + animations + états des régions.
 data.js      — TOUT le contenu équilibrable (const DATA).
 lang.js      — i18n FR/EN (const TRANSLATIONS, t(), setLanguage).
 game.js      — moteur : état, save, énergie, grille, racines,
                drag&drop, commandes, XP, bonus régions, sprites.
 map.js       — écran Carte : débloquer/purifier les régions.
 battle.js    — combat automatique par tours + fragments.
Ordre de chargement : data → lang → game → story → map → battle.
Sauvegarde : localStorage clé "routesDeLor_v1" (migration auto des
anciens états : champs manquants = valeurs par défaut).
Sprites : détection auto. Si assets/sprites/items.png existe (grille
10 col × 3 rangées, cellules 128×128, rangées = eco/creatures/utility,
colonnes = niveaux 1-10) il remplace les emojis partout (grille,
combat, ghost de drag). Si assets/sprites/enemies.png existe (6 col
× 1 rangée) il remplace les emojis ennemis. Sinon fallback emoji :
JAMAIS de combattant/case invisible.
Décors : assets/bg_<region>.png (1080×1920) appliqués au #bg-layer
quand la région est purifiée ; fallback = dégradé CSS par région.

story.js — moteur de récit (scènes dans data.js → DATA.scenes, 
portraits dans assets/portraits/)
